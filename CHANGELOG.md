# CHANGELOG

## 0.3.3

- Исправлена оценка ширины невидимых Unicode-контролов в таблицах; ширина spacing marks, в том числе без `Intl.Segmenter`, не изменилась.
- При `chunkSize=1` символы из суррогатных пар больше не разбиваются на некорректные строки. Обычное разбиение с лимитом 4096 не изменилось.
- Demo- и validation-серверы ограничили чтение файлов корнем репозитория, включая проверку внешних симлинков. Это инструменты разработки, не входящие в npm-пакет.
- README уточняет уровни заголовков, размер чанков и `random_id` в примере `vk-io`.
- Добавлены регрессионные тесты и CI на Node.js 22 и 24 с проверкой сборки, покрытия и npm-пакета.

## 0.3.2

- Публикация npm переведена на Trusted Publisher через GitHub Actions OIDC: workflow больше не использует `NPM_TOKEN`, отключает npm cache в release job и публикует пакет без долгоживущего npm-токена.
- Для пользователей API библиотеки изменений нет; релиз проверяет установку свежей версии из npm и provenance-аттестацию пакета.

## 0.3.1

- Разбиение длинных сообщений на чанки стало более естественным: библиотека по возможности сохраняет целыми абзацы, цитаты, таблицы и блоки кода в тройных обратных кавычках.
- При разбиении длинных форматированных фрагментов корректнее сохраняются `items` на границах чанков.
- При расчёте лимита чанка символ `@` учитывается ближе к ограничениям VK.

## 0.3.0

- Canvas-трансформ таблиц переведён в экспериментальный API: используйте `markdown-to-vk/experimental` и `createExperimentalCanvasTableTransform`.
- `@napi-rs/canvas` больше не ставится как обычная зависимость и подключается как optional peer dependency только для экспериментального canvas-режима.

## 0.2.0

- Добавлен `createCanvasTableTransform` для более точного выравнивания markdown-таблиц через canvas `measureText()`, включая жирный текст и эмодзи.
- Улучшено стандартное выравнивание таблиц за счёт более точной оценки ширины unicode-символов и форматирования.
- Улучшена обработка заголовков с unicode-пробелами и служебными символами в начале строки.
